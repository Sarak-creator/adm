# Development Rules for AnajakDiamond

## Automatic GitHub Synchronization
- **MANDATORY**: Whenever any code, component, API route, configuration, or documentation file is added, modified, or deleted, the assistant must **automatically** stage the changes, commit with a clear and descriptive commit message, and push to GitHub (`origin main`).
- Do not wait for the user to explicitly ask to push to GitHub; push automatically at the end of each task or code edit.
